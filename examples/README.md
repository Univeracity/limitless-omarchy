# Examples

The bundled catalog contains a source-free method instead of another user's
desktop configuration. It demonstrates a valid private-scope query without
requiring a network connection or a public Omarchy Plugin.

Run:

    limitless-omarchy query --catalog ./examples/catalog

    source-free-method
