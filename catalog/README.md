# Bundled local catalog

The bundled catalog gives the local agent connection a small, inspectable
source-free method without copying another user's desktop configuration. It is
available offline and requires neither a service connection nor a public
Omarchy Plugin.

Run:

    limitless-omarchy query --catalog ./catalog

Expected disposition:

    source-free-method

The matching draft is retained to make the sealed capsule inspectable.
Reseal it with Limitless Library whenever its contents change; do not hand edit
the digest-bound capsule record.
